**Reproducible phylogenetic commands of the HGT Analysis of the paper "Horizontal Gene Transfer from Fungi to Myxozoa: Genomic Evidence and Evolutionary Implications"**
# HGT__analysis_myxozoa
Abstract
Horizontal gene transfer (HGT) is increasingly recognized as an important mechanism driving evolutionary innovation in eukaryotes, yet its functional significance in parasitic lineages remain poorly understood. Myxozoans are obligate cnidarian parasites characterized by extreme genome reduction and complex two-host life cycles, making them an intriguing system for investigating the evolutionary role of HGT. We conducted a comparative genomic and transcriptomic analysis to identify and characterize candidate genes putatively transferred from fungi to myxozoans. Phylogenetic reconstruction, sequence composition analyses, and functional annotation provided multiple lines of evidence supporting ancient HGT events retained across diverse myxozoan species. Candidate transferred genes encode proteins putatively involved in carbohydrate metabolism, defense, and regulatory processes. Exploratory codon-usage analysis revealed compositional differences between candidate genes and the sampled reference sets, a pattern that may be consistent with partial amelioration following ancient transfer, although broader quantitative comparisons will be required to evaluate codon adaptation more rigorously. Molecular clock analyses place the inferred fungi-to-myxozoan HGT events within a time interval that overlaps with the major diversification of myxozoans, around 300 Ma. Collectively, these findings suggest that candidate horizontally acquired genes may have contributed to functional innovation during myxozoan evolution, expanding our understanding of the evolutionary impact of HGT in these highly reduced parasites.

Keywords: horizontal gene transfer, Myxozoa, fungi, molecular evolution, phylogenomics, molecular clock, parasitism



Computational Infrastructure and Reproducibility: 
All computational analyses were performed on high-performance computing clusters with appropriate resource allocation for memory-intensive phylogenetic calculations. The analysis pipeline was implemented using a combination of custom scripts (Python 3.8, R 4.5.0, MAFFT v7.471, trimAl v1.4.rev15, IQ-TREE v2.1.3, MrBayes v3.2.7, BEAST2 v2.6.3, Trimmomatic v0.39, Salmon v1.4.0, Trinity v2.11.0, HMMER v3.3.2, BlobTools v1.1.1, and Kraken2 v2.1.2. Version control was maintained using GitHub, and detailed documentation was provided for all analytical steps. Specifically, the complete sequence of IQ-TREE v2.1.3, MrBayes v3.2.7, BEAST2 v2.6.3, and Salmon v1.4.0 commands—with all parameter settings—is documentet (HGT_analysis_commands.sh). Computational reproducibility was ensured using containerized environments (Docker) and comprehensive logging of all parameter settings and software versions. 
Data management followed FAIR (Findable, Accessible, Interoperable, Reusable) principles, with all input data, intermediate results, and final outputs organized in a structured directory hierarchy with appropriate metadata. Quality control checkpoints were implemented at each major analytical step, with automated validation of file formats, data integrity, and expected output characteristics. All custom scripts and analysis pipelines are provided in to facilitate independent validation and reproduction of the analyses.

Use the Sequences: 
The fungal dataset comprised ten species: Aspergillus fumigatus (GCA_000002655.1), Candida albicans (GCA_000182965.3), Cryptococcus neoformans (GCA_000149245.3), Fusarium graminearum (GCA_000240135.3), Neurospora crassa (GCA_000182925.2), Rhizopus oryzae (GCA_000149305.2), Saccharomyces cerevisiae (GCA_000146045.2), Schizosaccharomyces pombe (GCA_000002945.2), Trichoderma reesei (GCA_000167675.2), and Ustilago maydis (GCA_000328475.2). 
The myxozoan dataset comprised seven species: Ceratomyxa sp. (GCA_040939075.1), Ceratonova shasta (GCA_918559645.1), Ellipsomyxa sp. (GCA_040938985.1), Henneguya salminicola (GCA_009887335.1), Myxobolus cerebralis (PRJNA182728), Myxobolus squamalis (GCA_010108815.2), and Sphaeromyxa zaharoni (GCA_001455285.1).


To repeat the work analysis, use your own dataset, then adapt the file HGT_analysis_commands.sh and run it from the terminal in Linux or use the file HGT_analysis.yml and run it after adaptation using Docker on any operating system.
